# 설문 통계표 생성기

데이터와 코드북을 올리면 문항 유형을 **자동으로 인식**해서 보고서용 통계표(배너 교차표)를 만들어 주는 웹 도구입니다.

- 🔒 **파일은 서버로 전송되지 않습니다.** 모든 계산은 사용하는 사람의 브라우저 안에서 이루어집니다.
- 결과는 화면에서 바로 보고, **엑셀(.xlsx)**·**한글(.hwpx)** 파일이나 같은 표를 뽑는 **SPSS 신택스(.sps)**로 저장할 수 있습니다.

## 사용 순서

1. **파일 올리기** – 데이터 파일(.xlsx/.xls/.csv)과 코드북(.xlsx)을 올립니다.
2. **문항 확인** – 자동으로 인식된 문항 유형을 확인하고, 틀린 것은 고칩니다. 표 제목도 여기서 바꿀 수 있습니다. 문항마다 **큰 순 정렬**을 켜면 보기가 전체 기준 비율이 큰 순서로 표시됩니다.
3. **표 설정** – 배너(성별·연령 등), 가중치 적용 여부, 표 모양, 소수점 자리수를 고릅니다.
4. **결과** – 표를 확인하고 `엑셀로 저장` 또는 `한글로 저장`을 누릅니다.

## 결과 화면 이동
- **결과 도구 모음**: 스크롤해도 화면 위에 붙어 있어, 어디서든 `엑셀로 저장`·`한글로 저장`·`표 설정 바꾸기`를 누를 수 있습니다. 지금 보고 있는 표 제목도 함께 보입니다.
- **표 목록(왼쪽)**: 지금 보고 있는 표가 강조되고 목록도 따라 움직입니다. 위쪽 검색 칸에 표 번호(`12`), 제목 일부, 변수명(`D2`)을 넣으면 목록이 줄어들고, `Enter`를 누르면 첫 번째 표로 이동합니다.
- **오른쪽 아래 버튼**: 스크롤을 조금 내리면 나타납니다. `맨 위`(파일 올리기), `설정`(3단계 표 설정), `결과`(결과 첫 표)로 바로 이동합니다.

## SPSS 신택스 저장
결과 화면의 `SPSS 신택스` 버튼을 누르면, 화면과 같은 표를 SPSS `TABLES` 명령으로 뽑는 신택스(`.sps`)를 받습니다. 사내 신택스 형식을 따릅니다.

- **구성**: 머리 주석 → `COMPUTE X=1` → `WEIGHT BY 가중치`(끄면 `WEIGHT OFF`) → 배너(`T_`/`V_` 변수, RECODE, 레이블) → 평균·척도·요약용 파생 변수 → 문항 변수·값 레이블 → `응답자 특성` 표 → 표마다 `TABLE` 명령 → `EXECUTE`
- **표 명령**: `/FORMAT ZERO MISSING('.')`, `/PTO=T1'■ 전 체 ■' T2''/FTO=T3'계'`, `/STA=COU(T2(PAREN6.0)'사례수') CPC(…(F4.1)'%':배너)`, `/CORNER="BASE=…"`, `/TITLE="표 N. …"` — 표 번호와 제목은 화면과 같습니다.
- **문항 유형별**: 단일 `BY T2+문항+T3` · 복수응답 0/1 `/MDG`, 보기 번호 방식 `/MRG` · 순위 1순위 표 + `/MRG` 종합 · 척도 `AA_`(평균)·`Y_`(100점)·`G_`(⊙ 긍정/보통/부정) · 수치 `C_`(사례수)·`AA_`(평균·표준편차 등) · 요약표 `C_` + `S1_`/`T2_`/`AA_`/`Y_`
- **넣지 않는 것**: 파일 경로(`CD`, `GET FILE`), 저장(`SAVE OUTFILE`). 데이터 파일을 먼저 연 뒤 실행하세요.
- **인코딩**: `3단계 표 설정 → SPSS 신택스 인코딩`에서 EUC-KR(기본, 한국어 코드페이지 모드) 또는 UTF-8(유니코드 모드)을 고릅니다.
- 화면의 "큰 순 정렬"은 신택스에 반영되지 않습니다(코드 순서).

## 한글(HWPX) 저장
- 한글 2014 이상(또는 한컴오피스 뷰어)에서 열 수 있는 `.hwpx` 파일로 저장합니다.
- A4 세로 문서에 **한 쪽에 표 하나씩** 들어갑니다. 쪽마다 `표 번호. 제목` → 표 → `※ 주석` 순서이고, 첫 쪽에는 생성일·사례수·배너·가중치 정보가 들어갑니다.
- 표 서식은 화면·엑셀과 같습니다: 머리글·배너 그룹 칸 병합, 머리글/전체/배너/통계 열 배경색, 숫자 오른쪽 정렬, 소수점 자리수.
- 표 하나가 한 쪽보다 길면(배너가 많은 경우 등) 다음 쪽으로 이어지고, 머리글 행이 다음 쪽에 반복됩니다. 표 너비는 본문 폭(150mm)에 맞추고, 열 너비는 글자 수에 따라 나눕니다.
- 빈 문서 틀은 python-hwpx(Apache-2.0)의 Skeleton.hwpx를 변환해 넣었습니다(`js/hwpx-template.js`, `lib/licenses/`).

처음이라면 `예시 파일로 해보기` 버튼으로 바로 체험할 수 있습니다.

## 파일 준비

### 데이터
- 1행에 변수명, 2행부터 응답자 1명당 1행
- 값은 코드 숫자(1, 2, 3 …). 빈칸은 무응답(해당 없음)으로 처리되어 Base에서 빠집니다.
- CSV는 UTF-8과 한글 윈도우(CP949) 형식 모두 읽습니다.

### 코드북 (`samples/코드북_양식.xlsx` 참고)

| 변수명 | 문항 | 코드 | 레이블 | 문항유형(선택) | 그룹(선택) |
|---|---|---|---|---|---|
| SQ1 | SQ1. 귀하의 성별은? | 1 | 남자 | | |
| | | 2 | 여자 | | |
| Q5 | Q5. 이용 횟수 | | | | |

- 보기마다 한 행. 변수명·문항은 첫 행에만 있어도 됩니다.
- `1=남자, 2=여자`처럼 한 칸에 보기를 모아 적은 코드북도 읽습니다.
- 제목행 이름은 `변수명/변수`, `문항/변수 레이블`, `코드/값`, `레이블/보기/값 레이블` 등 흔히 쓰는 표현을 알아봅니다.

## 코드북 형식(조사 시스템별)

조사 시스템마다 코드북 모양이 달라서, 형식별 읽기 규칙을 따로 둡니다. `1단계`의 **코드북 형식**에서 `자동 감지`(기본)를 두면 파일을 보고 알아서 고릅니다.

| 형식 | 알아보는 방법 | 읽는 내용 |
|---|---|---|
| 표준 양식(세로형) | 기본값 | 위의 `변수명·문항·코드·레이블·유형·그룹` 표 |
| INT64 | `GUIDE`, `GUIDE2`, `Variable Labels`, `Value Labels` 시트 | GUIDE의 문항유형(RADIO·CHECK·HCHECK·GRADE_CLICK·RADIOSET(S)·NUMBER·TEXT…), GUIDE2의 변수별 문항·보기, Value Labels의 코드 |

| G-CAII (사내) | `문항ID·문항타입·보기` 질문지 시트 + `Variable Labels`, `Value Labels` | 질문지의 질문번호·문항타입(SIG·MTP·MX1·MX3·MX7·RNK·NUM·OPN…), Variable Labels의 문항·단위, Value Labels(`1.'보기'`) |

G-CAII 코드북에 `Variable Labels`·`Value Labels` 시트가 없고 질문지 시트만 있으면, 데이터 변수명을 질문번호에 맞춰 변수를 만듭니다. 이때 데이터 쪽 접두어(`Y1` ↔ 질문 `1]`), 밑줄형 이름(`SQ2_1`, `Y4_3`, `Y20_1순위`, `SQ1_9997ET`), 영문 전체 문항타입(`단순응답형(Single Answer)`, `척도형(Matrix - single)` 등)도 알아봅니다.

G-CAII는 변수명 규칙으로 문항을 묶습니다: `B2M1`(복수응답) · `B4MT1`(행렬 단일 → 단일/척도 묶음) · `B5MT1M1`(행렬 복수 → 열별 복수응답, Base 전체) · `D3C1MT1`(행렬 멀티 → 열별 단일 묶음, 열 제목은 질문 문장에서) · `B7R1`(순위) · `C2N1`(숫자, 단위 표시) · `A1O1`/`P`/`E`(주관식·전화·메일 → 제외) · 질문번호의 `-`는 `K`(`B5-1` → `B5K1…`).

INT64 문항유형은 이렇게 바뀝니다: RADIO → 단일, RADIOSET → 척도, RADIOSETS → 단일/척도 묶음(보기로 판단), CHECK·HCHECK·CHECKSETS → 복수응답, GRADE_CLICK → 순위, NUMBER·HNUMBER → 수치, TEXT·TEXTAREA·ADDR → 제외.

새 형식은 `js/formats.js`에 어댑터를 하나 추가하면 됩니다.

## 자동 인식 규칙

| 유형 | 인식 기준 | 만들어지는 표 |
|---|---|---|
| 단일응답 | 코드북에 보기가 있음 | 보기별 % + 계 |
| 척도 | 보기가 연속 숫자(3~11점)이고 "매우/보통/만족/그렇다" 같은 표현 | 보기별 % + 긍정(Top2)·부정(Bottom2)·평균·100점 환산 (11점 척도는 부정 0~3점 · 보통 4~6점 · 긍정 7~10점) |
| 척도 묶음 | `Q2_1, Q2_2…`가 같은 척도 보기 공유 | 항목별 척도표 + 요약표(평균·100점·Top2) |
| 복수응답 | `Q3_1, Q3_2…` 값이 0/1(또는 1/빈칸)뿐이거나, 선택한 보기 번호/빈칸(`Q3_2`=2)으로 저장 | 항목별 선택 % (Base: 응답자) |
| 순위응답 | `Q4_1, Q4_2…`가 같은 보기를 쓰고 한 사람 안에서 값이 겹치지 않음 | 1순위 표 + 1+2순위(종합) 표 |
| 복수응답(코드형) | 위와 같지만 문항에 "모두/복수" 표현 | 보기별 선택 % |
| 수치 | 보기 없는 숫자 | 평균·표준편차·최솟값·중앙값·최댓값 |
| 제외 | 문자(개방형), ID, 가중치 변수 | 표 만들지 않음 |

- 코드북의 `문항유형` 칸에 `단일/척도/복수/순위/복수코드/수치/제외/가중치`를 적으면 자동 인식보다 우선합니다.
- 변수명 규칙과 다르게 묶고 싶으면 `그룹` 칸에 같은 이름을 적습니다.
- 척도의 "모름/무응답" 보기는 % 에는 나오지만 평균 계산에서는 빠집니다.
- 척도가 `1=매우 그렇다 … 5=전혀 아니다`처럼 거꾸로 되어 있으면 긍정이 높은 점수가 되도록 역산합니다.
- 코드북에 없는 변수(표본 정보 등)는 표를 기본으로 만들지 않지만 배너로는 쓸 수 있습니다. 이때 `DE1`(1,2,3) ↔ `주체분류`(`01.대기업`…)처럼 1:1로 맞는 문자 열이 있으면 보기 이름을 거기서 가져옵니다.
- 조사 시스템 관리 열(SEQ, UID, LOI, IP, USER_AGENT, begin_dt 등)과 문자 응답은 자동으로 제외합니다.
- 코드북에 없는 문자 열 중 값 종류가 적은 것(예: `data_지역`의 "서울", "경기")은 보기로 바꿔 배너로 쓸 수 있게 합니다.
- 숫자 문항의 `9999`, `999999`처럼 9로만 된 값은 모름/무응답 코드로 보고 평균에서 빼며, 표 아래에 건수를 적습니다.
- 개인정보 동의·연락처·패널 참여 같은 관리용 문항은 기본으로 체크 해제됩니다.
- 척도는 보기가 짧은 척도 표현("매우 만족", "그런 편이다")일 때만 인식하고, 긴 설명 문장형 보기는 단일응답으로 봅니다.
- 같은 보기를 쓰는 예/아니오 묶음(예: 사업별 인지 여부)은 항목별 표 외에 첫 보기 비율 요약표를 함께 만듭니다.
- 코드북에 없는 값이 데이터에 있으면 경고와 함께 "미정의 코드"로 표시합니다(데이터 클리닝 점검용).

## 보기 정렬 (큰 순서)
- `2단계 문항 확인`의 **큰 순 정렬** 칸에서 문항마다 켜고 끌 수 있고, `정렬 모두 켜기/끄기` 버튼으로 한꺼번에 바꿀 수 있습니다. 기본은 꺼짐(코드북 순서)입니다.
- 정렬 기준은 **전체** 행의 비율(가중치를 켰으면 가중 비율)이며, 배너 행도 같은 순서로 따라갑니다.
- 기타·모름·무응답·해당 없음·없음 같은 보기는 크기와 상관없이 맨 뒤에 둡니다. `계` 열도 그대로 맨 뒤입니다.
- 대상: 단일응답, 복수응답, 순위(1순위 표·1+2순위 표 각각), 복수응답(코드형), 단일응답 묶음의 요약표.
- 제외: 평균을 내는 수치 문항, 척도·척도 묶음(보기 순서 자체가 의미가 있음).

## 가중치
`표 설정`에서 가중치 적용을 켜고 변수를 고르면 %, 평균이 가중치로 계산됩니다. 사례수는 가중 전/가중 후/둘 다 중에서 고를 수 있습니다.

## 사이트 열기

- **인터넷 주소로 쓰기 (GitHub Pages)**: 저장소 `Settings → Pages → Source`를 **GitHub Actions**로 바꾸면 `main` 브랜치에 올릴 때마다 자동으로 배포됩니다.
- **내 PC에서 쓰기**: 폴더를 내려받아 `index.html`을 더블클릭하면 됩니다. (이 경우 `예시 파일로 해보기` 버튼 대신 예시 파일 링크를 내려받아 올려 주세요.)

## 개발자용

```bash
npm install
npm test          # 계산 검증 테스트
npm run samples   # samples/ 예시 파일 다시 만들기
```

| 파일 | 역할 |
|---|---|
| `js/core.js` | 표준 코드북 해석, 문항 유형 자동 인식, 표 계산 |
| `js/formats.js` | 코드북 형식(시스템)별 읽기 규칙 — 표준, INT64, G-CAII |
| `js/render.js` | 화면용 표 그리기 |
| `js/export.js` | 엑셀 저장 |
| `js/export-hwpx.js` | 한글(HWPX) 저장 |
| `js/export-spss.js` | SPSS 신택스(TABLES) 저장 |
| `js/hwpx-template.js` | 한글 빈 문서 틀 (`tools/make_hwpx_template.js`로 생성) |
| `js/app.js` | 화면 동작 |
| `lib/` | 엑셀 읽기(SheetJS)·쓰기(ExcelJS), 압축(JSZip) 라이브러리 — 라이선스는 `lib/licenses/` |
